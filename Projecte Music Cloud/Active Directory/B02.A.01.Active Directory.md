# Anàlisi de l’arquitectura

Responeu breument:

1.   Per què el servidor `SRV-AD-01` necessita una adreça IP fixa?
> Perque estigui identificat a la xarxa, ja que si estigues per dhcp el servidor ha de tenir resgitrar al equip amb un ip que no canvi cada vegada que es reinici
    
2.   Per què els clients del domini han d’utilitzar un servidor DNS capaç de resoldre la zona d’Active Directory?
> Perque l'active directory depen del dns un equip alhora de connectase a un ad
    
3.   Què passaria si `SRV-AD-01` estigués apagat?
> Tota la estructura de Music Cloud cauria, el usuaris no podrias accedir a les seves comptes.
    
4.   Per què un únic controlador de domini és acceptable al laboratori però insuficient en una empresa real?
> Perque un laboratori es un entorn de prova on no hi cap risc, en canvi a una empresa real si algun problema afecta a tota l'empresa.
    
5.   Per què els departaments no s’han creat com a dominis diferents?
