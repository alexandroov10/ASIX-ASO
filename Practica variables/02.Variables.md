## 5. Cometes

Executa:

```
$servidor = "SRV01"
```

Després:

```
Write-Host "Servidor: $servidor"
```

i:

```
Write-Host 'Servidor: $servidor'
```

Respon:

**Quina diferència observes? Per què creus que passa?**

> Amb les cometes dobles quan al ficar la variable dins del text mostra el contingut de la variable, en canvi amb les cometes simples no fa el canvi i mostra el nom de la variable.

> Aixo passa perque amb les cometes simples el powershell ho interpreta com un text literal i no veu la variable i amb les cometes dobles reconeix les variables i mostra el seu contingut

## 6. Guardar el resultat d'una ordre

Executa:

```
$serveis = Get-Service
```

Després:

```
$serveis
```

Respon:

- Què creus que conté $serveis?
> Conté els serveis del sistema
- La variable conté un únic valor o diversos elements?
> Diversos elements perque mostra molts serveis del sistema
