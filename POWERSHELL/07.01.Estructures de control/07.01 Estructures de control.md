## 2. if o switch

Crea:
```
$estat = 2
```
Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions. 

> IF:
```POWERSHELL
PS C:\Users\Administrator> if ($estat -eq 1) {
>> Write-Host "Iniciant"} elseif ($estat -eq 2) {
>> Write-Host "Executant"} elseif ($estat -eq 3) {
>> Write-Host "Finalitzat"} elseif ($estat -eq 4) {
>> Write-Host "En espera"} else {
>> Write-Host "Estat desconegut"}
Executant
PS C:\Users\Administrator>
```
> SWITCH
```powershell
PS C:\Users\Administrador>
PS C:\Users\Administrador> switch ($estat) {
>> 1 {Write-Host "Iniciant"}
>> 2 {Write-Host "Executant"}
>> 3 {Write-Host "Finalitzat"}
>> 4 {Write-Host "En espera"}
>> default {Write-Host "Estat desconegut"}
>> }
Executant
PS C:\Users\Administrador>
```
